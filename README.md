# Lumen — Camada Semântica "AI-Ready" + Agente Analítico Governado

> 🚧 Projeto em desenvolvimento. Nenhuma sprint além da Sprint 1 foi iniciada.

## Visão

O Lumen é um projeto de engenharia de dados e BI que constrói uma camada semântica
certificada sobre dados públicos de crédito e indicadores macroeconômicos do Brasil
(Banco Central, IBGE), com um agente analítico governado capaz de responder perguntas
em linguagem natural com base em métricas certificadas — sem gerar SQL/DAX livre.

## Status atual

- **Fase:** Sprint 1 — Fundação (repositório, ambientes, esteira CI/CD)
- **Última atualização:** agosto de 2026

## Stack planejada

Microsoft Fabric, PySpark, dbt, Delta Lake, Power BI (Direct Lake, DAX), 
GitHub Actions, LLM (agente analítico).
